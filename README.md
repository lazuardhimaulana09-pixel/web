## ⚡ Fitur Utama & Keunggulan

1. **Kecepatan & Performa Tinggi (Ultra-Fast Static Architecture)**:
   - Zero-dependency: Dibangun murni menggunakan **Vanilla Semantic HTML5**, **Modern CSS3 (Custom Properties & Flex/Grid)**, dan **Vanilla JavaScript**.
   - Tidak menggunakan library CSS berat pihak ketiga di sisi klien yang memblokir rendering.
   - Semua 12 dokumen sertifikat PDF telah dikonversi dan dioptimasi menjadi gambar berformat **WebP** ringan (~15–25 KB per thumbnail).
2. **Desain Responsif (Mobile & Desktop Friendly)**:
   - Desain *mobile-first* dengan hamburger drawer navigation yang halus pada iOS/Android.
   - Tipografi dinamis menggunakan `clamp()` yang menyesuaikan ukuran layar secara proporsional.
3. **Showcase 12 Sertifikat Resmi & Interaktif**:
   - Filter instan berdasarkan kategori: *Semua*, *Jaringan*, *Linux*, *Cyber Security*, *Python & Git*, *Mengetik*.
   - Fitur pencarian *real-time* berdasarkan judul, nomor sertifikat, maupun penerbit.
   - Tombol 1-klik **"Salin ID Sertifikat"** dengan indikator notifikasi toast.
   - Modal Lightbox untuk pratinjau sertifikat resolusi tinggi tanpa meninggalkan halaman.
   - Tautan langsung untuk membuka berkas PDF asli dan tautan verifikasi online resmi.
4. **Interactive Linux Terminal**:
   - Simulasi terminal interaktif dengan tab `profile.json`, `skills.sh`, `network.conf`, dan `neofetch`.
5. **Formulir Kontak Fungsional**:
   - Terintegrasi langsung dengan Web3Forms API ke email `lazuardhimaulana09@gmail.com`.
   - Dilengkapi proteksi anti-spam *honeypot* dan validasi input.

## 🚀 Menjalankan Secara Lokal

Untuk menguji website di komputer lokal:

```bash
# Menggunakan Python 3 HTTP Server
python3 -m http.server 8080
```

Buka browser dan akses: `http://localhost:8080`
